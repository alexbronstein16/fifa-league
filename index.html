Rules

Format

  • Everyone plays everyone twice, once home and once away.
  • Win = 3 points, draw = 1, loss = 0.
  • Ties in the table are broken by goal difference, then goals scored.
  • The top 4 make the playoffs: 1st vs 4th, 2nd vs 3rd, then a final.

Reporting

  • Report every game on the Report page right after it ends. League, playoff and friendly games all go there.
  • Either player can report. Enter your name, both players, and the score.
  • The commissioner approves each report before it counts, so it won't show up in the standings or Elo right away.
  • Playoff games that end level need the penalty shootout score.
  • Played with someone who isn't on the list? Ask the commissioner to add them as a guest, then report it as a friendly.
  • Got a score wrong? Message the commissioner and it'll get fixed.
